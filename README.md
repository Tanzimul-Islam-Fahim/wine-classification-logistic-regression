# Wine Classification Using Logistic Regression

## Project Overview
This project implements a machine learning classification model using Logistic Regression to classify wine samples into three different categories based on their chemical properties.

The project uses the built-in Wine dataset from Scikit-learn.

## Dataset Information
- Total samples: 178
- Number of features: 13
- Number of classes: 3
- Missing values: None

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Google Colab

## Methodology
1. Dataset loading and exploration
2. Data cleaning and preprocessing
3. Train-test splitting (80:20)
4. Feature scaling using StandardScaler
5. Model training using Logistic Regression
6. Model evaluation using accuracy, confusion matrix, and classification report
7. Feature coefficient analysis
8. Cross-validation
9. Saving and testing the trained model

## Model Performance
- Test Accuracy: 97.22%

The model was evaluated using a separate test dataset containing 36 samples.

## Project Structure
